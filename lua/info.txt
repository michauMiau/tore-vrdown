# Lua layers present in this mod:
#   vrinput.lua   action-driven input: reads controller state published into the
#                 store and maps it onto the game's own action names through
#                 the remap table the game itself writes from Lua
#                 (data/ui/components/input_options_logic.lua does
#                 SetString("options.input.keymap.<action>", key)). No offsets,
#                 no FFI. The native half supplies controller state; this half
#                 decides what it means.
#   vrhaptics.lua haptics triggers, driven by the engine's own PlayHaptic path
#   vrcamera.lua  per-eye camera parameters
#   vrbus.lua     the event protocol
#   main.lua      init/tick/update/draw glue and the settings overlay
#
# Store keys this mod owns, all under the savegame.mod. prefix the engine
# requires (mods get no private store):
#   savegame.mod.teardownvr.vr.*         config
#   savegame.mod.teardownvr.in.<button>  digital input, 0..1
#   savegame.mod.teardownvr.axis.<axis>  analog input, -1..1
